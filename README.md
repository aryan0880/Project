# NayePankh Foundation Website

A simple, responsive website built for NayePankh Foundation as a student intern project.

> Note: This is not the official website. Official site: [nayepankh.com](https://nayepankh.com)
 Pages

- Home – Hero, impact stats, four pillars, founder quote
- About Us – Story, team, values, NGO registration info
- Our Causes – Food, Education, Health & Hygiene, Clothing
- Donate – Amount selector, donor form, UPI details
- Contact – Contact details, social links, message form

 Features

- Responsive design (mobile + desktop)
- Smooth scroll-reveal animations
- Interactive donation amount buttons
- Mobile hamburger menu
- Toast notifications on form submit
- Single HTML file — no frameworks or libraries

 Tech Stack

- HTML, CSS, Vanilla JavaScript
- Google Fonts (Playfair Display + Inter)
  
 How to Run

Just open `index.html` in any browser. No setup needed.
